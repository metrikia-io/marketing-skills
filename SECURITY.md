# Security

## Reporting Security Issues

If you discover a security vulnerability in this repository, please report it via GitHub Security Advisories.

**Do not** open a public GitHub issue to report a security vulnerability. Instead:

1. Visit the repository's security page
2. Click "Report a vulnerability"
3. Describe the issue with as much detail as possible
4. Submit the draft advisory

GitHub will notify us, and we will work with you to verify and address the issue.

## Scope

Metrikia Marketing Skills is a documentation repository containing Claude Skills. The repository itself contains no runtime code, servers, databases, or executing services.

If you have a security concern about:

- A Claude Skill's methodology: describe the issue in a security advisory
- How to securely handle sensitive data while using these skills: we welcome that discussion

Typical examples of valid reports: instructions that could expose sensitive data, workflows that have information security gaps, or misleading guidance about handling credentials or proprietary information.

Examples that are not in scope for this repository: vulnerabilities in Claude, the Claude Code IDE, your local system, or external tools you use with these skills.

## Response Timeline

We will acknowledge security reports within 48 hours and provide a status update within 7 days.
